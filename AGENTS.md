# Changelog Instructions

- Document every repository change in the `changelog/` directory.
- Use one Markdown file per calendar day, named `YYYY-MM-DD.md` according to the `Europe/Berlin` timezone.
- Create the daily file when it does not exist. If it already exists, append the new entry without replacing or rewriting existing entries.
- Describe what changed, why it changed, and how it was verified.
- Reference related GitHub issues or pull requests when available.
- Keep changelog entries concise and group them under clear headings such as `Added`, `Changed`, `Fixed`, or `Removed`.
- Include the daily changelog file in the same commit as the change it documents.
- Do not modify changelog files from previous days unless correcting a factual error.
